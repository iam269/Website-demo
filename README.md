# Personal Portfolio Website — Ionița Aurel Mihai

A modern, single-page personal portfolio built with pure HTML, CSS & vanilla JavaScript. No frameworks, no dependencies — just fast, clean code.

> ⚠️ **Note:** This is an experimental project. All personal data, work experience, and information displayed on the website are entirely fictional and used for demonstration purposes only.

## 🌐 Live Demo

👉 [iam269.github.io/Website-demo]([https://iam269.github.io/Website-demo/](https://itsiamdev.github.io/Website-demo/))

## ✨ Features

- **Bold dark aesthetic** with gold accents and Bebas Neue typography
- **Smooth scroll animations** triggered on viewport entry (IntersectionObserver)
- **Animated skill bars** that fill on scroll
- **Responsive design** — works on mobile, tablet, and desktop
- **Active nav highlighting** based on scroll position
- **Zero dependencies** — no npm, no build step, just open `index.html`

## 🗂 Sections

- **Hero** — Name, tagline, and call-to-action
- **About** — Bio and key stats
- **Skills** — Animated competency cards
- **Experience** — Chronological timeline
- **Contact** — LinkedIn, email, and phone links

## 🚀 Getting Started
```bash
git clone https://github.com/iam269/Website-demo.git
cd Website-demo
open index.html
```

## 🛠 Tech Stack

- HTML5
- CSS3 (custom properties, clip-path, animations)
- Vanilla JavaScript (IntersectionObserver API)
- Google Fonts (Bebas Neue, Outfit, DM Mono)

## 📝 Customization

Edit the placeholder sections in `index.html`:
- Personal bio and description
- Work experience (companies, dates, roles)
- Contact details (email, phone)
- Skill names and proficiency levels
